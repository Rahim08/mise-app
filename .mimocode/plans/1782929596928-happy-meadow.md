# Plan: 7 Native iOS Features

## Overview
Add 7 features to the native iOS app, all with toggleable notification settings.

## Features

### 1. Additional Siri Shortcuts (#2)
**File**: `native/Mise/Mise/MiseShortcuts.swift`
- Add `OpenShiftIntent` — "Открой смену" (opens Manager with today's date)
- Add `AddExpenseIntent` — "Запиши расход X за категорию" (creates shift_expense)
- Add `BookingCountIntent` — "Сколько броней сегодня" (reads snapshot)
- All read from AppGroup snapshot (offline, instant)

### 2. Analytics Swipe Comparison (#7)
**File**: `native/Mise/Mise/AnalyticsView.swift`
- Add swipe gesture on AnalyticsView to switch between current and previous month
- Show previous month's data as comparison indicator (delta % and colored arrow)
- Store `compareMonth` offset in model, reset on tab switch

### 3. Low Stock Push (#9)
**Files**: `native/Mise/Mise/StashView.swift`, server-side
- After tobacco_stock update, check if any flavor < min_quantity_g
- If yes, send push via `/api/notify` with type `low_stock`
- Server: add handler in `lib/notify.ts` for `low_stock` type
- Toggle: `notification_prefs.prefs.low_stock` (default: on)

### 4. Voice Tasks (#12)
**Files**: `native/Mise/Mise/PeopleView.swift`, `native/Mise/Mise/SpeechManager.swift`
- Add microphone button to Tasks tab
- SpeechManager already handles recognition → transcript
- Parse transcript: "Задача: помыть кальянную" → create staff_task with title
- AI-assisted parsing via `/api/ai` with module=tasks (reuse existing AI endpoint)

### 5. Shift End Reminder (#14)
**Files**: `native/Mise/Mise/ManagerView.swift`, `native/Mise/Mise/Push.swift`
- When shift is opened, schedule a local `UNNotificationRequest` for shift_end_time - 30min
- When shift is closed, cancel the pending notification
- Use `UNUserNotificationCenter` (local, not remote)
- Toggle: `notification_prefs.prefs.shift_reminder` (default: on)

### 6. Quick Actions (#16)
**File**: `native/Mise/Mise/MiseApp.swift`
- Register `UIApplicationShortcutItem` in AppDelegate
- Items: "Новая бронь" (opens Bookings), "Открыть смену" (opens Manager), "Сегодняшние брони" (opens Bookings → today)
- Handle in `application(_:performShortcutItem:)` → deep-link to module

### 7. Offline Caching (#18)
**File**: `native/Mise/Mise/DB.swift`
- Add in-memory cache layer: `CacheStore` (actor) with TTL (5 min for reads)
- On network failure, return cached data with `stale: true` flag
- Cache key = hash of payload (table + filters + order)
- Write-through: mutations invalidate related cache entries
- UI shows subtle "stale" indicator when showing cached data
- **NOT SwiftData** — too risky for production. Lightweight cache is sufficient.

## Settings Toggles
**File**: `native/Mise/Mise/MainView.swift` (notification settings sheet)
- Add toggles for each push feature:
  - `notif_low_stock` — Low stock alerts
  - `notif_shift_reminder` — Shift end reminder
  - `notif_voice_tasks` — Voice task confirmation
- Stored in `notification_prefs.prefs` JSON column (existing infrastructure)
