Доступ для команды

Вход без паролей.

Каждый сотрудник входит в своё приложение через QR и PIN. Без регистрации, без email, без забытых паролей.

QR-вход

Владелец показывает QR. Сотрудник сканирует — и устройство привязывается к заведению навсегда.

PIN-доступ

4-значный PIN задаёт владелец. Каждому сотруднику — свой код и свой набор приложений.

Face ID

После первого входа — предложение включить Face ID. Следующие входы мгновенны.
