О нас

Мы строим будущее ресторанного бизнеса.

Mise — платформа управления рестораном созданная людьми из ресторанного бизнеса. Мы знаем как работает смена изнутри и делаем инструменты которые реально помогают.

Наша миссия

Дать владельцам и менеджерам ресторанов простые и красивые инструменты для управления бизнесом. Без сложных настроек, без лишних функций — только то что нужно каждый день.

Мы начинали с одного ресторана и одного приложения. Сегодня Mise — это три продукта для менеджеров, владельцев и кальянных залов, и мы только начинаем.

Наши продукты

📋 Mise Manager — для менеджеров. Открытие смены, учёт операций, инкассации и итоговый отчёт.

📊 Mise Analytics — для владельцев. Финансовая аналитика, зарплаты, статистика по сменам.

💨 Mise Stash — для кальянных залов. Склад табака, приход, расход и инвентаризация.
